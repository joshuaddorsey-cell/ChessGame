# Josh's Chess Game

A desktop chess game written in Java Swing. It supports local two-player games and computer opponents with multiple difficulty levels.

## Features

- Legal move validation, check, checkmate, stalemate, castling, en passant, and pawn promotion
- Computer opponent with selectable difficulty
- Undo, move history, captured pieces, board themes, clocks, and sound settings
- Save and load games using `.jchess` files

## Run in Eclipse

1. Open Eclipse and choose **File > Import**.
2. Select **General > Existing Projects into Workspace**.
3. Select this repository folder as the root directory and finish the import.
4. Open `src/Chess/ChessGUI.java` and choose **Run As > Java Application**.

The project uses Java 21.
